05 / REQUIREMENTS

PROMPT IS NOT A SPECIFICATION

AI에게 말을 잘하는 것보다
완료를 정의하는 것.

BAD PROMPT
“고객 문의를 AI가 알아서 잘 답하게 만들어줘.”
사용자?범위?데이터?실패 기준?보안?
VERIFIABLE SPEC
  • 목적 승인된 지식문서에 근거해 1차 답변 제공
  • 범위 배송·환불·계정 문의만 자동 응답
  • 안전 결제·법률·위협 표현은 상담원에게 100% 이관
  • 품질 근거 링크 포함률 ≥ 95%, PII 노출 0건
  • 성능 정상부하에서 p95 응답시간 3초 이내
  • 증거 골든셋·보안테스트·운영로그로 검증
※ 수치는 세미나용 예시이며 서비스 위험도에 맞게 합의해야 합니다.
